**Data Structure Simulator** 
is an interactive educational project designed to help students understand fundamental data structures through simple visual representations. The simulator covers **Stack, Queue, Linked List, and Tree**, along with their basic operations such as insertion, deletion, searching, and traversal. The project uses **HTML and CSS** for the interface and **JavaScript** for implementing the data structure operations and functionality. The main aim is to make learning data structures easier, more interactive, and practical for students.
